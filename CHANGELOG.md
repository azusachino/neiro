# Changelog

## 0.1.0

- First version: `get`, `search`, `list`, `nav`, `links`, `backlinks`, `unresolved`, `journal`, and `capture`, as a Bun SDK and a compiled CLI.
- `capture` creates one new inbox note in the vault's frontmatter conventions, and can commit and push it.
- Vault conventions are read from an optional `neiro.toml`.
