# Code of conduct

This is a small, personal project. Be respectful in issues, pull requests, and any other discussion here. No harassment, personal attacks, or discriminatory language or behaviour.

Disagreement about a design decision is welcome; see [CONTRIBUTING.md](CONTRIBUTING.md). Disagreement conducted disrespectfully is not.

Report a violation through the contact on the maintainer's GitHub profile. Reports are handled privately, and repeated or severe violations lead to removal from the project's spaces.
